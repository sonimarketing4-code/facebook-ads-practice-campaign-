# Facebook Ads Practice Campaign – UrbanBite Café

## Project
A simulated Facebook Ads campaign created as part of the Unified Mentor Facebook Ads Practice Campaign project.

**Business:** UrbanBite Café (fictional)  
**Tagline:** Fresh. Fast. Made for Your Day.  
**Campaign duration:** 7 days  
**Practice budget:** ₹10,000

## Objective
Drive website visits and build awareness for a fictional café offering affordable meals, snacks and beverages.

## Important note
This is a **practice/simulated campaign**. No real Facebook advertising spend or real business performance is being claimed. The analytics in the report are sample figures created for academic demonstration.

## Files
- `index.html` – project presentation/deployment page
- `campaign_report.md` – detailed project report
- `feedback_video_script.md` – script for the required feedback video
- `ad_copy.txt` – campaign ad copy
- `mock_analytics.csv` – simulated campaign metrics

## Campaign summary
- Objective: Website Traffic + Brand Awareness
- Formats: Single Image, Carousel, Short Video
- Audience: 18–35, urban Indian audience
- Budget: ₹10,000 over 7 days
- Primary CTA: Learn More
